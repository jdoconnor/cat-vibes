# Cat Vibes

## Origin Story

> hi. my name is kratos. i'm not the regular user of this computer. i'm looking to vibe code something fun. oh yeah, i forgot -- i'm a cat. make something cool.

## What is this?

An interactive cat playground where you are the cat. Chase treats, catch stars, and unleash zoomies.

## How to play

- **Move mouse** — chase the cursor
- **Click** — spawn treats
- **Space** — ZOOMIES mode

## Run

Open `index.html` in a browser.
